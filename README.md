# REXchange: Your Campus Connect

Build a modern, responsive college-only exchange platform called "REXchange". The purpose is to help students exchange unused resources, services, skills, opportunities, and items within their college community.

The platform should support books, electronics, event tickets, study materials, skills/services, giveaways, and exchange requests.

Create these main sections:

Landing/Login page

Student dashboard

Explore marketplace with search, categories and filters

Listing details page

Create a listing page

AI Match page

Messages/requests page

Student profile and reputation page

The key differentiating feature should be an AI-powered matching system. When a student posts something they need or something they want to offer, the system should identify relevant listings and display a match percentage no specific numbers are required to be mentioned but with a little explanation of why they match.

Include options to Sell, Exchange, Give Away, Offer a Service, and Request Something.

Each listing should contain an image, title, description, category, condition, price or exchange preference, department, year, and availability.

Add a trust/reputation system where students can rate completed exchanges.

Use realistic sample student data and listings so the application can be demonstrated without requiring real users.

Design the application as a polished hackathon-winning product: modern college-focused UI, clean cards, intuitive navigation, excellent typography, responsive design, subtle animations, clear call-to-action buttons, and a professional but youthful appearance.

Prioritize a fully functional prototype over unnecessary features. All important buttons and navigation should work.
